## Project setup

```bash
$ git clone https://github.com/yabtsegaAschalew/CoursesAPI-using-NestJS.git
```

```bash
$ yarn install
```

## Compile and run the project

```bash
# development
$ yarn run start

# watch mode
$ yarn run start:dev

# production mode
$ yarn run start:prod
```
## Testing APIs

First open Postman
Go to Files on the top left corner
Select Import under the files tab
Then drag and drop "Courses.postman_collection.json" from the cloned folder.
